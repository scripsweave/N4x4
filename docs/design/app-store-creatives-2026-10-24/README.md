# N4x4 App Store header and search artwork

Research and image concepts, 24 October 2026. Generated with the built-in
`image_gen.imagegen` tool using N4x4's ChromeRing and authentic Duo workout
capture as references. Exact prompts: [prompts.json](prompts.json).

## Recommendation

Use **A's chrome-ring header** for immediate brand recognition, with **A's
search composition** making the interval-training purpose clear. B offers a
more abstract depiction of four work efforts and three recovery valleys.

## What these placements do

The optional product-page header introduces the app visually; the search
creative can replace the default preview/screenshot presentation in search.
These placements are available on iOS/iPadOS 27+. Creative assets can be
submitted separately through Asset Library and, after approval, used without
a new app binary. This allows a separate artwork workflow while 5.10 is in
review. [Apple's asset-management guide](https://developer.apple.com/help/app-store-connect/manage-app-information/manage-your-app-store-assets)

## Production requirements

These are concept-resolution images, not upload-ready exports. Both headers
are 1916×821; search is 1536×1024. Dedicated final exports must meet Apple's
requirements: header 3840×1646 (21:9), search 1920×1280 to 3840×2560 (3:2),
or a shared universal 5244×2950 PNG. No transparency. Header/search videos
can be 5–30 seconds, 30/60 fps; search video remains muted.
[Apple's creative specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/creative-assets-specifications)

The search concept contains an AI-rendered device and interface based on
the real capture. Before production, use the unmodified app capture and
accurate device geometry, or a screen-only treatment. Do not treat the
generated UI as an authentic screenshot. Check responsive crops and text
legibility in Apple's templates and App Store Connect Preview, including
light/dark appearances, phone/tablet orientations and Duo.
[Apple's design resources](https://developer.apple.com/app-store/asset-best-practices/)

The submitted app/version, existing screenshots and review evidence were not
modified during this design exploration. No main push or Cloud build was made.
